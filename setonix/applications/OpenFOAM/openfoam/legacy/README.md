# Legacy OpenFOAM container recipes

The recipes in this directory are retained for historical reference and as
possible starting points for users who need to reproduce older OpenFOAM
environments.

These recipes were previously known to build and run correctly
in compatible environments. However, they have not been validated in the
current Setonix environment and will no longer be updated or maintained.

These recipes are now archived and are not expected to work with current
Ubuntu releases, package repositories, or container build infrastructure.

The recipes may depend on obsolete or unavailable software and may contain
known or unknown security vulnerabilities. They should not be assumed to be
suitable for production use.

No compatibility, build-success, or security guarantees are provided.

The actively maintained OpenFOAM recipes are located in the parent directory.
